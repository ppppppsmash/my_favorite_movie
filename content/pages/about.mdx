**シネリスト**は、「次に何を観るか」で迷ったときの道しるべになることを目指した、映画のキュレーションサイトです。

## このサイトでできること

- **リストから探す**: ジャンル、テーマ、スタイル、国、監督、俳優、受賞歴。10のカテゴリに分けた厳選リストから映画を選べます
- **シリーズの観る順番を確認する**: スター・ウォーズやマーベルなど、長いシリーズの観る順番と「飛ばしていい作品」を整理しています
- **配信状況を確認する**: 各作品ページでは、日本国内の主な動画配信サービスでの配信状況を表示しています
- **新作・トレンドをチェックする**: ランキングページで、今週のトレンドや日本の公開予定を確認できます

## 選定の方針

リストの作品は、編集部が実際に観た作品のなかから、以下の基準で選んでいます。

1. 今観ても古びていないこと
2. 日本で配信・ソフトなどの手段で観られること
3. 観終わった後に誰かと話したくなること

ランキング形式のリストを除き、順番に優劣はありません。

## データについて

作品の基本情報(タイトル、公開年、あらすじ、評価、キャスト、ポスター画像)は [The Movie Database (TMDB)](https://www.themoviedb.org/) の API を利用しています。配信情報は TMDB を通じて [JustWatch](https://www.justwatch.com/) から提供されています。

This product uses the TMDB API but is not endorsed or certified by TMDB.

評価の数値は TMDB ユーザーによる投票の平均値で、当サイト独自の評価ではありません。
