## 掲載情報について

本サイトに掲載している作品情報(あらすじ、公開年、評価、キャスト等)は、[The Movie Database (TMDB)](https://www.themoviedb.org/) の API から取得したものです。配信情報は TMDB を通じて [JustWatch](https://www.justwatch.com/) が提供するデータに基づいています。

これらの情報は定期的に更新していますが、配信状況や価格は予告なく変更されることがあります。最新の情報は各サービスの公式サイトでご確認ください。

本サイトの情報を利用したことによって生じた損害について、本サイトは一切の責任を負いません。

## 著作権について

本サイトに掲載しているポスター画像、場面写真、キャスト写真等の著作権は、各作品の製作者・配給会社・権利者に帰属します。これらの画像は TMDB の API を通じて配信されているものを、作品紹介の目的で表示しています。

本サイトのリストの構成、コメント、記事本文の著作権は本サイトに帰属します。無断転載はご遠慮ください。引用の際は出典として本サイトへのリンクを明記してください。

## 削除依頼について

掲載内容に権利上の問題がある場合は、[お問い合わせ](/page/contact)よりご連絡ください。確認のうえ、速やかに対応いたします。

本サイトは Google AdSense および Amazon アソシエイト・プログラムをはじめとするアフィリエイトプログラムに参加しています。広告やアフィリエイトリンクを経由した商品・サービスの購入について、本サイトは一切の責任を負いません。

アフィリエイトリンクには `rel="sponsored"` 属性を付与し、広告であることを明示しています。
